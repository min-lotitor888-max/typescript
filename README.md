# TypeScript — Домашнее задание

Домашнее задание по TypeScript в рамках курса JavaScript от Нетологии.

## Описание проекта

В проекте реализована типизация товаров и работа с корзиной покупок.

Используется TypeScript, Jest, ESLint и Webpack.

## Реализованные классы

### Buyable

Общий интерфейс для товаров.

Содержит основные свойства:

- `id` — идентификатор товара;
- `name` — название товара;
- `price` — цена товара.

### Book

Класс книги, реализующий интерфейс `Buyable`.

Дополнительные свойства:

- `author` — автор;
- `pages` — количество страниц.

### MusicAlbum

Класс музыкального альбома, реализующий интерфейс `Buyable`.

Дополнительное свойство:

- `author` — исполнитель.

### Movie

Класс фильма, реализующий интерфейс `Buyable`.

Дополнительные свойства:

- `author` — режиссёр;
- `duration` — продолжительность фильма.

## Cart

Корзина хранит товары типа `Buyable`.

Реализованы следующие методы:

- `add(item)` — добавить товар в корзину;
- `getTotalPrice()` — получить общую стоимость товаров без скидки;
- `getTotalPriceWithDiscount(discount)` — получить стоимость товаров с учётом скидки;
- `deleteById(id)` — удалить товар по идентификатору;
- `items` — получить список товаров в корзине.
